AI Workflow

This page shows the AI working practices I would bring to a pursuit team, with a library of routines and example prompts. I built this site with Claude Code agents in the same way.

Based on Wipro's published AI announcements, the Loopio 2026 RFP benchmark, PPN 017 and my work at Atlas Learn, 27 October 2026.

This site

How this site was built

I built this site with Claude Code: four research agents wrote sourced files, page agents wrote the pages to a shared brief, and three independent reviewers checked them. Scripts checked every page in a browser at two sizes and ran an accessibility scan. The Method page lists every agent with its brief and run statistics.

In a pursuit team

Routines I would bring to pursuits

The same method works on a live pursuit: an agent does the first pass, and a named person checks it before anyone relies on it. Wipro already works with both model families, through its Applied AI Centre of Excellence for Claude and its Gemini Enterprise rollout to more than 10,000 AI-certified specialists.
